# Project Summary
Le projet "L'instant de Beauté" développe une maquette vitrine one-page pour un institut de beauté à Saint-Cergues. L'objectif est d'offrir une présentation attrayante des soins disponibles, des horaires, et une expérience de réservation fluide par téléphone. La maquette vise à refléter une ambiance spa haut de gamme, intégrant des éléments modernes pour séduire les clients.

# Project Module Description
- **Structure** : Contient le contenu et les sections de la page (index.html).
- **Style** : Gère la direction artistique et le responsive design (style.css).
- **Interactions** : Inclut la logique pour le carrousel des avis, le menu mobile, et les animations de défilement (script.js).

# File Description Inventory
- **index.html** : Page d'accueil qui redirige vers la maquette.
- **style.css** : Fichier de style pour l'apparence générale.
- **script.js** : Fichier JavaScript pour les interactions et animations.
- **linstantbeaute-x7m9/** : Dossier contenant la structure complète de la maquette, mise à jour avec de nouvelles sections et animations.

# Technology Stack
- HTML5 sémantique
- CSS3 (variables personnalisées, grid, flexbox, animations)
- JavaScript (vanilla), GSAP, Lenis

# Usage
1. Cloner le dépôt.
2. Installer les dépendances nécessaires.
3. Construire la maquette en exécutant les scripts.
4. Ouvrir `index.html` dans un navigateur pour visualiser la maquette.
